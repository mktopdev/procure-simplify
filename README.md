# Transxpress ERP

Enterprise logistics, customs, transportation, procurement, finance & fleet
management platform for Transxpress SARL.

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Postgres, Auth, Storage)

## Local development

```sh
npm install
npm run dev
```

## Database

Schema changes live in `supabase/migrations/`. See
`docs/phase1-deployment-and-uat.md` for the deployment and UAT process.
